# MLI-001 Production / QC Checklist

## Before voice
- [ ] Script fact-checked against research brief.
- [ ] All fictional figures clearly treated as illustrative.
- [ ] No accidental financial advice.
- [ ] Nova pronunciation check: nominal, OECD, disposable income.

## Voice
- [ ] One consistent Nova voice.
- [ ] Confident documentary/comedy cadence.
- [ ] Do not artificially slow to 0.9x unless natural.
- [ ] Export WAV, 48 kHz preferred.

## Visual
- [ ] Family-Dad visual bible only.
- [ ] Major visual event every ~2–5 seconds.
- [ ] Plain/light backgrounds dominate.
- [ ] One main idea per shot.
- [ ] Hard cuts are the default.
- [ ] Avoid complex physical environments.
- [ ] Avoid infographic-wall compositions.
- [ ] Public figures only when the episode requires them.

## Audio
- [ ] Narration always intelligible.
- [ ] Music very low under narration.
- [ ] SFX used for emphasis, not every cut.
- [ ] Loudness normalized consistently.

## Packaging
- [ ] Thumbnail readable at phone size.
- [ ] Title complements thumbnail; does not repeat all its text.
- [ ] Sources added to description.
- [ ] Captions uploaded.
- [ ] End screen has next-video placeholder or subscribe element.

## After publishing
Record at 24h / 7d:
- Impressions
- CTR
- Views
- Average view duration
- Average percentage viewed
- First 30s retention
- Subscribers gained
- Traffic sources
