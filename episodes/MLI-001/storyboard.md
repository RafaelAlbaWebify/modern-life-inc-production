# MLI-001 Storyboard v1

Target duration: ~9:12  
Major visual beats: 56  
Average beat length: ~9.9 seconds

This is intentionally a **micro-scene storyboard**, not an animation script. Each beat should be achievable using reusable vector figures, icons, diagrams, text and simple motion primitives.

## Production implication

The first renderer does **not** need general-purpose animation.

It only needs:
- figure placement;
- asset swapping;
- text;
- icons;
- arrows/lines;
- opacity;
- position;
- scale;
- simple reveals;
- scene transitions.

If a storyboard beat cannot be expressed with those primitives, simplify the beat before expanding the renderer.
