## Retention diagnosis

The main retention problem is not the narrator. It is repeated explanatory structure:

1. claim
2. research qualification
3. caveat
4. exception
5. restatement

That pattern repeats enough times that the middle can feel predictable.

The solution is not a more energetic voice. The solution is:
- compress repeated caveats;
- vary section structure;
- use concrete examples before research language;
- deliver mini-payoffs sooner;
- use visual pattern interrupts.
