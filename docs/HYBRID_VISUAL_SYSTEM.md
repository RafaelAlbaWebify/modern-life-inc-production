# Hybrid Visual Production System v1

## Principle

Modern Life Inc. is not produced by one closed renderer.

It uses a hybrid compositor with three scene classes:

### SYSTEM
Reusable assets + text + diagrams + simple motion.

Best for:
- explanatory beats
- comparisons
- heuristics
- recurring interaction patterns
- evidence cards
- phone/message scenes

### HYBRID
Generated illustration or custom visual + system overlays/motion.

Best for:
- emotional transitions
- visual metaphors
- scenes where static reusable assets would feel repetitive
- moments that benefit from richer composition but still need labels/arrows/text

### HERO
Unique high-impact generated illustration.

Best for:
- hook
- major conceptual turns
- memorable metaphors
- section pivots
- conclusion / synthesis

## Reuse rule

Reuse assets aggressively.
Reuse compositions sparingly.

The goal is visual consistency without template fatigue.

## Variation target

Every 20–30 seconds the viewer should see a substantially different visual construction, not merely a rearrangement of the same two characters.

## Approximate mix per 8–9 minute episode

- SYSTEM: 55–65%
- HYBRID: 20–30%
- HERO: 10–15%

These are targets, not hard quotas.

## Generated-image role

Generated images should:
- inherit the channel’s visual language;
- avoid photorealism unless explicitly needed;
- preserve dark charcoal + ivory + amber/orange palette;
- use editorial psychological illustration;
- avoid embedded text whenever possible;
- leave space for later overlays;
- be framed for 16:9 video use.

## Motion on generated images

Allowed:
- pan
- slow zoom
- crop reveal
- parallax
- foreground drift
- vignette/highlight
- overlay icons/arrows/text

Avoid fake animation that breaks anatomy or introduces visual artifacts.

## Production flow

script
→ storyboard
→ classify each beat SYSTEM / HYBRID / HERO
→ generate or select visual base
→ composite overlays
→ motion
→ QA
→ encode

## Quality gate

If a scene feels visually repetitive:
1. change composition;
2. change scale/crop;
3. change metaphor;
4. escalate SYSTEM → HYBRID;
5. escalate HYBRID → HERO only if necessary.

Do not solve repetition by endlessly adding new renderer features.
