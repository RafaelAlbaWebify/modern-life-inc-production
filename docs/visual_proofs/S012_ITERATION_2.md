# Visual Proof Iteration 2 — Lessons

## What iteration 2 proved

The storyboard-collage format is useful for planning but should not become production art.

Problems:
- too much embedded text;
- too many sub-scenes inside one generated image;
- insufficient negative space for compositor overlays;
- still too close to cinematic romance illustration;
- difficult to reuse as a clean visual base.

## Iteration 3 target

Generate a **single 16:9 editorial frame** for S012:
- one scene only;
- two simplified human figures;
- flat/editorial shapes;
- reduced facial detail;
- subtle café suggestion, not a fully rendered environment;
- charcoal / ivory / amber palette;
- no text;
- no arrows;
- no baked-in gaze lines;
- generous negative space for overlays;
- visually compatible with SYSTEM scenes.

## Acceptance criteria

The frame should:
1. read clearly at mobile size;
2. feel psychological/editorial rather than romantic/cinematic;
3. support compositor overlays without fighting them;
4. look reproducible across many different topics;
5. preserve the Modern Life Inc. brand palette.
